# Tibi 产品页设计约定

## 定位与页面结构

- 品牌固定为 **Tibi 提比**，定位为「AI first的英语学习全能助手」。首屏主标题分两行：「AI first的英语学习全能助手，」与「陪你英语阅读从入门到精通」，以听、说、读、写、词、练六个单字标签说明学习范围；标题、description 与 OG 同步定位，紧接下载按钮、平台信息和真实应用首页界面。删除重复定位的眉题，主文案为「读喜欢的英文，听一句、跟一句，把新词用进自己的表达」。
- 页面顺序为：hero 顶部狐狸装饰 → 产品价值与应用首页 → 无需账号／本地优先／MIT 开源事实条 → 六步功能 → 完整应用截图 → 隐私说明 → 下载与安装说明。
- **吉祥物仅作装饰配图，不设介绍文案/专区**。不设置角色故事、贴纸展区或 `#mascot`，导航无吉祥物入口；所有标题与文案围绕英语学习、AI 陪伴、隐私和下载。保留页头 `logo.svg`，产品 UI 截图仍是主要展示依据。
- 首屏图片、原图链接与分享预览均使用 `/img/screenshots/home.jpg` 首页截图，展示粘贴英文、导入网址与提问入口；分享预览使用绝对地址 `https://tibi.ferecord.com/img/screenshots/home.jpg`。截图轮播仍按 reader / home / words 排列；不增加虚构商店窗口、评价、用户数或媒体背书。
- 功能依次解释兴趣材料、朗读与跟读、语境词汇、AI 讲解与文字陪练、听写与造句纠错、学习观察与建议，每张卡片正文仅用一句话。图片继续展示现有阅读与词汇界面；原型卡片各有可见「界面原型」标签，不重复添加示例数据、实际版本或点击原图提示，不以截图暗示完整语音或写作工作台。
- 能力边界依据只读产品仓库 `README.md`、`docs/guide/README.md` 第 4／6／7／8 节：阅读、词汇、AI 理解与复习是当前基础；「听」来自原文朗读、调速、单句循环和听写，「说」指听后自行跟读模仿，「写」指造句练习及连接模型后的批改。AI 学伴通过文字对话讲解用法、辅助表达与练习，不宣称实时语音对话、发音评分或独立作文评测系统。连接模型的条件与可能产生的服务商费用仅在下载区 details 集中说明一次。
- 「无需账号、本地优先、MIT 开源」依据产品仓库 README、PRIVACY 和使用指南；隐私卡片保留 AI 内容发给所选模型服务商的说明。平台信息紧邻 CTA；系统版本、安装方式、模型费用、联网与同步说明集中在下载区 details。
- 下载入口指向 GitHub Releases；安装与模型费用说明使用原生 details。保持域名 `https://tibi.ferecord.com` 和源码链接 `tumars/tibi`。

## 字体根因与修复（2026-11-01）

旧 AI／复习／统计功能图来自 `docs/prototypes/*.html`。其 `v2.css` 注册并回落到 Alibaba PuHuiTi 3.0，原采集日志也记录了普惠体子集下载。字体已被画进图片，修改落地页 CSS 无法修复。正式应用没有使用普惠体。

本轮直接读取只读产品仓库 `apps/desktop/src/styles.css` 的三个字体栈：

```css
--f-ui: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
--f-read: Charter, "Bitstream Charter", "Charis SIL", Georgia, serif;
--f-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
```

- 真实界面优先：复用已有桌面 Web 构建的 `?mock=1` 截图调试模式，使用应用原生 React/CSS 与内置示例数据，不连接 Core、不访问个人学习记录，也不修改产品仓库。
- AI／统计 mock 接口不完整，复习 mock 的答案数据与当前界面有错位，因此这三张保留原型来源，不能称为真实应用实拍。
- 原型 CSS 在进入浏览器前移除 `@font-face` 和所有普惠体回落项，替换为上述精确字体栈；阻止第三方字体加载。源仓库文件保持只读。
- Mac Chrome headless 以 1280×800、DPR 2、浅色模式采集，等待 `document.fonts.ready` 及图片解码；通过 Chrome `CSS.getPlatformFontsForNode` 记录实际字体，并检查没有请求普惠体资源。
- 旧完整截图与产品仓库图片哈希一致，但位图不足以证明采集字体；本轮全部重新生成，不沿用旧图。

## 布局、交互与性能

- 视觉方向为「童趣但专业」：奶油白 `#fffaf2` 背景，首屏淡杏色柔光，白色产品卡片；陶土色 `#984425` 主按钮，杏橙标记与薄荷绿辅助色，链接和焦点保留克制蓝色。正文用深暖灰，截图保持原色；不增加卡通背景、花哨字体或大面积角色画面。
- 通用卡片圆角 22px、主按钮 16–18px、下载容器 32px；首屏标题用浅杏色下划线，六个学习标签与功能序号使用略不对称的小圆角，形成轻巧的学习便签感。颜色用于装饰与分组，不作为唯一信息标识。首屏狐狸与文案居中，完整首页截图横跨内容区，页面 UI 使用与应用一致的系统字体栈。
- 移动端从 320px 起可读；功能与隐私卡在 900px 以下两列、560px 以下单列，导航逐级精简。按钮至少 44px，360px 以下首屏按钮整行显示。
- 首屏 H1 使用 `clamp(20px, 6vw, 50px)`、1.4 倍行高与 `-.025em` 字距；显式换行配合 `white-space: nowrap` 保持两行及 `AI first` 连贯，第二行保留浅杏色下划线。标题上边距为 0、下边距为 12px，收紧狐狸与正文之间的留白。
- 完整截图保留 8:5 原始比例，可打开原图；六张局部图为 16:10，每组提供 `.webp` 与 `.sm.webp`。首屏首页图保留 1920×1200 宽高声明及 `fetchpriority="high"`，其他产品图片懒加载，均声明宽高。
- 首屏 `.hero-fox` 为 hero 的第一个元素，位于标题和主文案上方，居中作为顶部主要装饰焦点；无眉题与首页图注。狐狸使用产品同款 SVG 藏狐 idle 动画，由独立本地 `public/js/fox.js` 挂载，保留轻摇尾巴、呼吸、眨眼与耳朵微动的 CSS 循环；移除其他状态与点击交互，不增加框架或视频依赖。装饰不覆盖产品界面，其余装饰仍用透明底 WebP。
- 首屏装饰容器及 SVG 均为 `aria-hidden="true"`，不可聚焦，桌面固定 184×184px、560px 以下固定 128×128px，加载前后正方形占位一致。HTML 内保留空 alt 的 `onboarding-read.webp`，顶部回退图不懒加载，脚本禁用或加载失败时直接显示；减少动态效果时 CSS 立即停止全部狐狸动画，保持平静静态姿势，运行中切换偏好也生效。其余 WebP 保留空 alt、明确宽高、异步解码与懒加载。
- 保留一次性显现动画、焦点样式与跳到正文入口；学习标签错峰轻轻进入，按钮悬停仅上移 2px，曲线略带弹性，不循环漂浮。减少动态效果时关闭动画、位移和滚动过渡；JavaScript 禁用时内容完整可见。
- Swiper 11.2.10 距截图区 600px 内才从固定版本 CDN 加载。不自动播放、不循环，支持触摸、中文读屏提示、分页、前后按钮和区域内方向键；当前截图链接进入 Tab 顺序。
- 基础布局全在本地 CSS。CDN 失败或禁用脚本时回退静态截图网格；打印展开所有截图。已彻底删除 Three.js、WebGL 和贴纸动画，无对应网络请求。
- 无构建步骤，仅发布本站 `public/`。设计文档和截图脚本不发布；不更改 DNS、域名映射或其他站点。

## 重新采集

工具脚本：`scripts/capture-ui.cjs`。需要本机 Chrome、Node、Playwright 和 sharp；不为静态站增加运行时依赖。

先在两个终端分别启动只读本机服务（示例产品路径按实际位置设置）：

```sh
python3 -m http.server 8871 --bind 127.0.0.1 --directory /path/to/tibi/apps/desktop/dist
python3 -m http.server 8872 --bind 127.0.0.1 --directory /path/to/tibi/docs/prototypes
```

再运行：

```sh
TIBI_APP_PATH=/path/to/tibi node sites/tibi/scripts/capture-ui.cjs
```

如果依赖不在 Node 默认搜索路径，设置 `TIBI_CAPTURE_DEPS` 指向包含 playwright、sharp 的 node_modules；可用 `TIBI_CHROME` 指定 Chrome 可执行文件。脚本生成 15 张发布图片，字体报告和原型核对截图默认写入 `/tmp/tibi-capture-proof/`。
