# Tibi 产品页设计约定

## 调研：阅读学习产品的落地页模式

本轮（2026-11-01）先归纳竞品模式，再审查与修改页面。浏览器连接不可用，公开站点抓取也因 DNS 解析失败未成功；以下为这些产品的已知定位与长期常见营销模式，不代表对其当前版本的逐屏核验，不引用未经核实的用户数、评分或转化数据。

| 参考 | 可借鉴的模式 | 提比的取舍 |
| --- | --- | --- |
| [LingQ](https://www.lingq.com/en/) | 用感兴趣的真实内容学习，把阅读、查词和词汇积累串起来 | 首屏讲阅读收益，功能按学习过程排序；不宣称自带海量课程 |
| [Beelinguapp](https://beelinguapp.com/) | 故事、双语对照与音频让阅读方式容易理解 | 用清晰界面证明体验；不把桌面工具包装成分级读物订阅库 |
| [Readlang](https://readlang.com/) | 阅读中点词翻译，再用词卡复习；核心动作简单 | 突出「点词查义 → 原句复习」，少堆技术缩写 |
| [沉浸式翻译](https://immersivetranslate.com/)及同类工具 | 以具体阅读场景、翻译前后效果和安装入口降低理解成本 | 保留 UI 裁切图，交代 AI 需要连接模型；不承诺任何网页都能导入 |
| [Duolingo](https://www.duolingo.com/) | 单一清晰行动、友好角色、短句和重复入口 | 保留藏狐的亲和感；不借用连续打卡压力、排行榜或夸张庆祝 |
| [Apple](https://www.apple.com/mac/)式产品页与精简 SaaS 页面 | 大标题留白、产品视觉、一段一个价值点、渐进展开细节 | 保持暖净克制；不添加大视频、滚动劫持或复杂 3D 叙事 |

- **首屏：承诺 → 证据 → 主行动。** 一句话交代「读想读的英文、逐步熟悉生词」，短说明讲具体用法。主按钮下载提比，次按钮看真实界面；平台与可选 AI 条件紧邻按钮。沿用品牌插画，产品证据由紧随其后的 UI 卡片与完整截图承担。
- **社会证明与信任。** 成熟产品常用真实评分、媒体或用户评价；提比尚无可核实的此类素材。采用「无需账号、本地保存、MIT 开源」事实条，并提供源码、许可证与隐私说明；不虚构评价、数字或合作标志。区分本地存储和 AI 请求会发送给所选模型服务商。
- **叙事优先于堆功能。** 六张卡保留，但用编号、动作标题与短说明建立导入、标词、查词、深入理解、复习、回看进步的顺序。技术细节退到必要的说明，不把实现架构当作用户收益。
- **产品视觉。** 局部 UI 解释单个动作，完整截图解释工作台。真实截图与原型须有可见标注，不能仅靠 alt 区分；完整截图不裁掉边缘内容，附简短任务型说明。
- **CTA 节奏。** 导航与首屏进入下载区；截图后设轻量下载入口；页尾提供安装包与指南。外链按钮明确写 GitHub，不弹窗催促、不在每张卡上重复按钮。
- **动效与交互。** 保留短促淡入、有限贴纸浮动、手动截图轮播。Swiper 临近视口才加载；Three.js 在首屏资源加载后空闲时初始化，节省流量模式不加载装饰。减少动态效果时无位移、无 WebGL；离屏或后台不持续渲染。静态内容始终是基础。
- **移动优先。** 320px 起可阅读；中屏导航及时收起次要项，卡片依次变两列与单列；主要触控目标至少 44px。保留清晰焦点、跳到正文入口、图片尺寸与懒加载；截图可滑动，也能打开原图查看细节。

## Review：优化前审查

- **优点：** 中性底色、暖橙藏狐与克制蓝色一致；六张 WebP UI 图比泛插画更能证明功能；图片已有响应式来源。`#shots` 无自动播放，方向键仅在轮播内生效；Swiper/CDN/WebGL 失败可回退。Three.js 网格少、像素比有限，离屏与后台暂停；减少动态效果与键盘焦点已有基础支持。
- **文案与层级：** 首屏同时出现双语说明、SQLite、FSRS、MCP，阅读收益被术语分散；首个按钮写 Releases、第二个去源码，学习者缺少先看体验的路径。「导入什么都行」「点词就懂」过于绝对。截图区讲配色规则，吉祥物区讲仓库素材复用，属于内部设计说明。
- **信任与节奏：** 原型只在 alt 里注明；「数据在你电脑上」后两张卡却介绍朗读与 MCP，主题不一致；AI 配置与数据发送边界不够醒目。功能、截图、吉祥物之间缺少下载提示，页尾安装信息挤成一段。
- **布局与素材：** `.privacy .card` 继承零内边距，`.ico` 未限定尺寸，容易让插画挤压正文；完整截图用固定 `16/11` 与 `object-fit: cover` 会裁切。平板单列首屏的插画缺少高度约束；窄中屏仍保留全部导航，存在挤压风险。
- **可访问性与性能：** 首屏以外的贴纸和隐私插画未懒加载；完整截图缺少宽高；没有跳过导航入口。Swiper 和 Three.js 页面打开即请求；贴纸两轮浮动共 10 秒偏长，非交互卡片悬浮位移像可点击控件。需保留渐进增强，减少装饰抢占首屏资源。

## 实现约定

- 产品名称为 **Tibi 提比**；标题、搜索与分享摘要、正文和无障碍文案保持一致。
- 沿用现有中性底色、白色卡片和暖橙藏狐素材，资源均在 `public/img/`。
- 首屏采用中文受众说明、两行价值标题、简短用法、下载与查看界面按钮；平台和可选模型要求紧邻 CTA。首屏下方仅用「无需账号、本地优先、MIT 开源」可查证事实建立信任。产品事实依据只读产品仓库的 `README.md`、`PRIVACY.md` 和 `docs/guide/README.md`，不添加虚构用户数据。
- 功能区 `#features` 使用 `public/img/features/` 的 UI 裁切图：导入、标生词、查词来自真实应用截图；AI 阅读、复习、统计来自与应用视觉一致的高保真原型。卡片上方为 16:10 圆角媒体区，图片铺满裁切，下方保留标题与说明；WebP 以 `.sm.webp`（600×375）和 `.webp`（1200×750）提供 1x/2x 资源，延迟加载并附带描述界面的替代文本。功能卡片不再使用吉祥物缩略图，其他区域保留品牌贴纸；`#shots` 继续展示完整应用截图。
- 功能卡保留六张与现有顺序，增加 01–06 学习步骤；后三张显示「界面原型」，并在区尾说明素材来源。卡片间距 20px、正文内边距 22px，手机间距 16px；非交互卡片不再悬浮抬升或放大图片。
- 首屏文案依次淡入上移；装饰贴纸每轮 2.4 秒、两轮后停止，总时长不超过 5 秒。功能卡片、截图、吉祥物区、隐私卡片和下载区进入视口时仅显现一次。
- 悬停反馈仅面向支持悬停的精细指针设备；键盘焦点清晰可见。减少动态效果时关闭动画、位移反馈和平滑滚动；禁用 JavaScript 或缺少 IntersectionObserver 时直接显示内容。
- 截图区渐进增强为 Swiper 11.2.10（jsDelivr 固定版本），距离视口 600px 内才请求，不循环、不自动播放。桌面按卡片宽度展示并露出下一张，560px 以下每次一张；支持触摸滑动、44px 分页与前后按钮、聚焦轮播后的左右方向键及中文读屏提示。原图链接仅当前张进入 Tab 顺序，失败回退时恢复全部链接。完整截图按原始 1920×1200 比例展示，附宽高并可点击看原图。布局样式保留在 HTML，不依赖 CDN 样式；脚本禁用或 CDN 加载失败时完整显示静态截图网格，900px 以下单列。打印时也展开全部截图。
- 首屏原藏狐图与贴纸始终保留；Three.js r170（jsDelivr 固定版本）在右下角增加品牌蓝球体、暖橙小球和淡墨圆环。仅随指针或触摸轻微倾斜，无自动旋转，闲置、离屏或页面隐藏时停止渲染。仅三个低面数网格，无阴影和后期处理，像素比上限 1.5；画布为读屏忽略的装饰，不阻止触摸滚动。
- Three.js 等页面 load 后在空闲时初始化（无空闲回调 API 时下一任务执行）；节省流量时跳过。WebGL 不可用、Three.js 加载失败或上下文丢失时回退原图；减少动态效果时不加载或销毁 WebGL，Swiper 切换时长为零。支持浏览中更改该偏好。
- 900px 以下首屏、吉祥物和下载区单列，首屏插画高度限为 320px；760px 以下收起导航隐私和源码项，560px 以下功能与隐私卡片单列，首屏插画按 3:2 呈现，导航保留品牌和下载按钮。按钮点击区域至少 44px 高，360px 以下首屏按钮整行排列。提供跳到正文入口，原图链接使用内描边焦点，防止被圆角容器裁掉。
- 隐私卡恢复 24px 内边距、12px 间距，插画限制为 48px；内容统一为本地记录、可选 AI、开源查证，附指南、隐私与源码链接。补充网页、订阅、首次模型包下载和主动同步的联网边界，避免「本地优先」被理解为所有功能绝不联网。
- 吉祥物区使用陪伴型用户文案。截图后增加轻量下载 CTA；页尾提供系统范围、明确的 GitHub 安装包入口和使用指南，首次安装与模型计费说明使用原生 details 渐进展开。首屏插画高优先级，其余正文插画与截图延迟加载；本轮不增加图片文件或第三方依赖。
- 域名保持 `https://tibi.ferecord.com`，目录保持 `sites/tibi`，GitHub 链接保持 `tumars/tibi`。HTML 内联样式及基础显现脚本，增强交互集中于 `public/js/interactions.js`，两个 CDN 模块独立加载、独立回退。无构建步骤，仅发布 `public/`；本文不作为公开资源发布。
