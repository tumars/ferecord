# Tibi 产品页设计约定

- 产品名称为 **Tibi 提比**；标题、搜索与分享摘要、正文和无障碍文案保持一致。
- 沿用现有中性底色、白色卡片和暖橙藏狐素材，资源均在 `public/img/`。
- 首屏文案依次淡入上移；装饰贴纸轻浮两轮后停止，避免持续干扰阅读。功能卡片、截图、吉祥物区、隐私卡片和下载区进入视口时仅显现一次。
- 悬停反馈仅面向支持悬停的精细指针设备；键盘焦点清晰可见。减少动态效果时关闭动画、位移反馈和平滑滚动；禁用 JavaScript 或缺少 IntersectionObserver 时直接显示内容。
- 截图区渐进增强为 Swiper 11.2.10（jsDelivr 固定版本），不循环、不自动播放。桌面按卡片宽度展示并露出下一张，560px 以下每次一张；支持触摸滑动、44px 分页与前后按钮、聚焦轮播后的左右方向键及中文读屏提示。布局样式保留在 HTML，不依赖 CDN 样式；脚本禁用或 CDN 加载失败时完整显示静态截图网格，900px 以下单列。打印时也展开全部截图。
- 首屏原藏狐图与贴纸始终保留；Three.js r170（jsDelivr 固定版本）在右下角增加品牌蓝球体、暖橙小球和淡墨圆环。仅随指针或触摸轻微倾斜，无自动旋转，闲置、离屏或页面隐藏时停止渲染。仅三个低面数网格，无阴影和后期处理，像素比上限 1.5；画布为读屏忽略的装饰，不阻止触摸滚动。
- WebGL 不可用、Three.js 加载失败或上下文丢失时回退原图；减少动态效果时不加载或销毁 WebGL，Swiper 切换时长为零。支持浏览中更改该偏好。
- 900px 以下首屏、吉祥物和下载区单列；560px 以下功能与隐私卡片单列，导航保留品牌和下载按钮。按钮点击区域至少 44px 高，360px 以下首屏按钮整行排列。
- 域名保持 `https://tibi.ferecord.com`，目录保持 `sites/tibi`，GitHub 链接保持 `tumars/tibi`。HTML 内联样式及基础显现脚本，增强交互集中于 `public/js/interactions.js`，两个 CDN 模块独立加载、独立回退。无构建步骤，仅发布 `public/`；本文不作为公开资源发布。
