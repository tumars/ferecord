# Tibi 产品页设计约定

## 定位与页面结构

- 品牌固定为 **Tibi 提比**，定位为「AI first的英语学习全能助手」。首屏主标题保留两个逻辑行：「AI first的英语学习全能助手，」与「陪你英语阅读从入门到精通」，以听、说、读、写、词、练六个单字标签说明学习范围；标题与 OG 标题同步定位，description 概括导入、点词、AI 学伴、原句复习和本地优先。主文案为「读喜欢的英文，点词就懂、有问就答，复习用的是你读过的原句」。
- 页面顺序为：hero 顶部狐狸装饰 → 主文案（H1、引导语、学习标签、下载入口、平台信息）→ `#shots` 六张完整应用截图轮播 → 无需账号／本地优先／MIT 开源价值卡片 → `#features` 功能（四个重点 → 「还有这些」六张小卡 → 四项纯文字能力）→ 隐私说明 → 下载与安装说明。首屏次要按钮为「看看界面」，指向 `#shots`。页头导航为界面、功能、AI 学伴（`#companion`，功能区里的第三个重点）、隐私、源码和下载。
- **吉祥物仅作装饰配图，不设介绍文案/专区**。不设置角色故事、贴纸展区或 `#mascot`，导航无吉祥物入口；所有标题与文案围绕英语学习、AI 陪伴、隐私和下载。保留页头 `logo.svg`，产品 UI 截图仍是主要展示依据。
- `#shots` 轮播依次为 home / reader / chat / feeds / review / stats，图注各一句：首页导入与提问、阅读器里点词看语境释义、右侧同时开着总结面板、对话里的辨析与练习卡、订阅自动送来并标难度、复习面板、统计与洞察。分享预览继续使用绝对地址 `https://tibi.ferecord.com/img/screenshots/home.jpg`。不增加虚构商店窗口、评价、用户数或媒体背书。
- 功能区以「从读到懂，从懂到记住」为题，按学习顺序突出四个重点：01 读（导入各种材料与订阅，News in Levels 三档难度）、02 读懂（只标你标过的词，词卡先给这句里的意思）、03 AI 学伴（对话卡片、读到哪问到哪、写入前按权限先问且可撤销）、04 记住（FSRS 排期、原句出题、练习与造句批改）。每个重点为大图加一句说明和三条要点，桌面左右交替，900px 以下单列且文字在图上方；AI 学伴一段用淡靛蓝到杏色的底色区分。「还有这些」六张卡为：在阅读器里问 Tibi、导入就有总结、帮你找文章、听一句跟一句（朗读）、离线词典、看得见进步（统计）；最后一行纯文字列出浏览器剪藏、生词导出、接入其他 AI 工具（MCP）、多设备同步（文件夹或 WebDAV）。
- 能力边界依据只读产品仓库 `README.md`、`docs/guide/README.md` 第 4／6／7／8 节：阅读、词汇、AI 理解与复习是当前基础；「听」来自原文朗读、调速、单句循环和听写，「说」指听后自行跟读模仿，「写」指造句练习及连接模型后的批改。AI 学伴通过文字对话讲解用法、辅助表达与练习，不宣称实时语音对话、发音评分或独立作文评测系统。连接模型的条件与可能产生的服务商费用仅在下载区 details 集中说明一次。
- 「无需账号、本地优先、MIT 开源」依据产品仓库 README、PRIVACY 和使用指南；隐私卡片保留 AI 内容发给所选模型服务商的说明。平台信息紧邻 CTA；系统版本、安装方式、模型费用、联网与同步说明集中在下载区 details。
- 下载入口指向 GitHub Releases；安装与模型费用说明使用原生 details。保持域名 `https://tibi.ferecord.com` 和源码链接 `tumars/tibi`。

## 截图来源（2026-11-04 重拍）

全部产品图都是真实 Tibi 界面，不再使用 `docs/prototypes` 原型，也不再使用 `?mock=1`（mock 缺对话、订阅、统计等接口）。做法：

- 用产品仓库的 Vite 界面（`apps/desktop`）连一个临时演示 Core（`scripts/demo-core.mts`）：独立的临时库、产品仓库的离线词典，不读本机学习数据，也不碰任何 API Key。

- `scripts/seed-demo.mjs` 经 Core 接口导入三篇内置示例、按原句标生词和已知词、做一半复习、添加订阅；只有过去四周的阅读与复习记录（统计趋势）直接写进临时库。订阅文章是采集当天从内置源实际抓到的。

## 布局、交互与性能

- 视觉方向为「童趣但专业」：奶油白 `#fffaf2` 背景，首屏淡杏色柔光，白色产品卡片；陶土色 `#984425` 主按钮，杏橙标记与薄荷绿辅助色，链接和焦点保留克制蓝色。正文用深暖灰，截图保持原色；不增加卡通背景、花哨字体或大面积角色画面。
- 通用卡片圆角 22px、主按钮 16–18px、下载容器 32px；首屏标题用深暖灰引题与陶土色大字区分主次，六个学习标签使用略不对称的小圆角。颜色用于装饰与分组，不作为唯一信息标识。首屏狐狸与文案居中，页面 UI 使用与应用一致的系统字体栈。hero 狐狸与文案间距为桌面 24px／手机 20px，底部留白为 20px／16px，紧接截图区。
- 截图区沿用奶油白页面背景，移除独立底色、上下边线与重复「界面」眉题，保留可访问的 H2「导入、阅读、积累，一处完成」，字号 20–26px；上下留白 24／32px，让完整 UI 尽早出现。后续分区保留「价值／怎么学／隐私／下载」短标签。
- 价值区沿用奶油白背景，三张等宽卡片以半透明白色表面、20px 圆角、陶土色细边和轻阴影承载承诺；小圆点配浅杏色圆环，20px 深暖灰标题与 14px 副文案区分层次。保留「无需账号／打开就能开始」「本地优先／学习记录留在本机」「MIT 开源／自由使用与修改」。560px 以下纵向单列，标题与副文案上下排列，不用固定文字列宽；不使用通栏泥色底、左竖线或大号展示字。
- 功能与隐私区保持奶油白留白，最后以更深杏色渐变和 56px 主按钮收尾。普通分区留白 48–88px，移动端 48px；价值区上下留白桌面 40／24px、手机 24／16px。
- 四个重点用 `.spot` 两栏网格（文字 5 : 图 7，偶数行图在左），图片 16:10、22px 圆角加柔和阴影；「还有这些」沿用 `.features` 三列卡片（900px 两列、560px 单列），文字在图上方；纯文字能力为四列浅底小块（900px 两列、560px 单列）。
- 移动端从 320px 起可读；功能与隐私卡在 900px 以下两列、560px 以下单列，导航逐级精简。按钮至少 44px，360px 以下首屏按钮整行显示。
- 首屏 H1 分为两个块级逻辑行：第一行用深暖灰 `#60584f`、`clamp(17px, 2.8vw, 30px)`、500 字重、1.45 倍行高及 `.035em` 字距；第二行用陶土色 `#984425`、`clamp(32px, 5.2vw, 64px)`、800 字重、1.2 倍行高及 `-.04em` 字距，取消浅杏色下划线。两行间距 12px，桌面字号约为 1:2；第二行按「陪你英语阅读／从入门到精通」两个短句分组，窄屏优先在短句之间换行，文字放大时组内也可换行。`AI` 与 `first` 间保留不换行空格。主文案最大宽度为 960px，标题上边距为 0、下边距为 24px；引导语仍独立限制宽度并居中。
- 完整截图保留 8:5 原始比例，可打开原图；六张局部图为 16:10，每组提供 `.webp` 与 `.sm.webp`。产品截图集中于截图区及功能卡，均懒加载并声明宽高，完整截图仍为 1920×1200。
- 首屏 `.hero-fox` 为 hero 的第一个元素，位于标题和主文案上方，居中作为顶部主要装饰焦点；无眉题与首页图注。狐狸使用产品同款 SVG 藏狐，由独立本地 `public/js/fox.js` 挂载；保留呼吸与轻点头，以 10 秒 CSS 循环串起双耳错峰微动、单眨与双眨、瞳孔左右偷瞄，以及短暂微笑、脸颊变红、4px 小跳和加快摇尾，地面阴影同步轻缩。嘴形仅用透明度交替，沿用产品嘴部与舌头配色；无状态机、定时器或点击交互，不增加框架或视频依赖。装饰不覆盖产品界面，其余装饰仍用透明底 WebP。
- 首屏装饰容器及 SVG 均为 `aria-hidden="true"`，不可聚焦，桌面固定 184×184px、560px 以下固定 128×128px，加载前后正方形占位一致。HTML 内保留空 alt 的 `onboarding-read.webp`，顶部回退图不懒加载，脚本禁用或加载失败时直接显示；减少动态效果时 CSS 立即停止全部狐狸动画，保持平静静态姿势，运行中切换偏好也生效。其余 WebP 保留空 alt、明确宽高、异步解码与懒加载。
- 一次性显现与导航状态集中在 `public/js/interactions.js`。首屏标题、标签、按钮及初始视口内内容直接显示；仅对首屏下方的分区标题、价值项、功能／隐私卡、轮播和下载容器启用显现，移除已删除首屏截图的选择器。功能卡和价值项错峰 0／60／120ms，显现完成后移除延迟；按钮与截图悬停上移 2px，卡片上移 3px 并加柔和阴影。保留清晰焦点与跳到正文入口，不捕获整页按键。
- 页头滚动超过 12px 后增加模糊底与阴影；界面、功能、AI 学伴、隐私、下载导航随阅读位置更新 `aria-current="location"` 和下划线，导航及交互脚本的章节列表均与 DOM 顺序一致，页底仍能识别下载区。使用被动滚动监听与每帧合并更新，不拦截原生锚点跳转。
- 减少动态效果时关闭显现、悬停位移、动画和滚动过渡，运行中切换立即显示所有内容；JavaScript 禁用或交互脚本失败时内容完整可见。狐狸在减少动态效果与打印时停止全部动画和过渡，回到闭嘴、正视、淡腮红的平静静态姿势。
- Swiper 11.2.10 距截图区 600px 内才从固定版本 CDN 加载。不自动播放、不循环，支持触摸、中文读屏提示、分页、48px 陶土色前后按钮和区域内方向键；当前截图链接进入 Tab 顺序。图注附简短编号和界面名称，分页使用陶土色强调当前项。
- 基础布局全在本地 CSS。CDN 失败或禁用脚本时回退静态截图网格；打印展开所有截图。已彻底删除 Three.js、WebGL 和贴纸动画，无对应网络请求。
- 无构建步骤，仅发布本站 `public/`。设计文档和截图脚本不发布；不更改 DNS、域名映射或其他站点。

## 重新采集

需要本机 Chrome、Node 22+、产品仓库（已 `pnpm install`、已生成 `data/ecdict/dict.db`），以及装有 `playwright-core`、`sharp` 的目录；不为静态站增加运行时依赖。三个终端分别运行（`TIBI_APP_PATH` 指向只读产品仓库）：

```sh
TIBI_APP_PATH=/path/to/tibi /path/to/tibi/packages/core-node/node_modules/.bin/tsx sites/tibi/scripts/demo-core.mts
VITE_CORE_WS=ws://127.0.0.1:3466 /path/to/tibi/apps/desktop/node_modules/.bin/vite --port 1430 /path/to/tibi/apps/desktop
node sites/tibi/scripts/seed-demo.mjs
```

演示库默认在 `/tmp/tibi-demo`（`TIBI_DEMO_DIR` 可改，Core 与种子脚本要一致）。然后在浏览器打开 `http://localhost:1430`，在应用里发三段对话（演示模型按这几句给回答）：首页点建议「推荐一篇 10 分钟左右的科技文章」并保留候选卡不作答；首页问「affect 和 effect 怎么区分？」，接着说「好，出几道题练练」；在《How a Compiler Sees Your Code》阅读器里打开 Tibi 面板问「lexer 和 parser 有什么区别？」。最后：

```sh
TIBI_CAPTURE_DEPS=/path/to/node_modules node sites/tibi/scripts/capture-ui.cjs
```

原图写到 `/tmp/tibi-capture-raw`（`TIBI_CAPTURE_RAW` 可改），再按脚本里的裁切表生成 6 张 JPEG 和 20 张 WebP；`--publish-only` 只重新裁切。`TIBI_CHROME` 可指定 Chrome 路径。
