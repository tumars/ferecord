读你感兴趣的英文文章，
顺便把英语学会。

Tibi（提比）是给中文母语学习者的英语阅读学习工具：按你的水平标生词，点一下看「这句里」的意思，读过的词自动进复习。内容存在本机，不必注册账号。

Read English you actually care about — and learn the language along the way. Open source, privacy-first.

它能做什么

从导入到复习，一条连贯的阅读学习路径；AI 按需出现，不连模型也能读、查词、复习。

导入什么都行

网址、粘贴英文、EPUB、PDF、Word、图片与扫描版 PDF（本地 OCR），浏览器剪藏一键发送。

按水平标生词

先花约 3 分钟测词汇量，之后只标出你可能不认识的词；读得越多越准。

点词就懂

词卡给出「在这句里」的意思（AI 生成、可缓存），也有 ECDICT 词典、音标和发音。

AI 帮你读

导入时总结、挑短语和长难句；整篇译文、选中追问、在对话里继续问 Tibi。

记得住

生词进 FSRS 复习，用的是你读过的原句；还有听写、拼写、易混词、造句批改。

看得见进步

已知词、每日阅读、复习表现、学习日历；打开统计时 Tibi 会写一段观察和建议。

应用内空状态、庆祝、引导和贴纸都用同一角色；本页配图复用仓库已定稿的吉祥物素材，不再另造形象。

数据在你电脑上

没有账号、没有遥测。只有你主动用到的功能才会联网：抓取你导入的网页、调用你配置的模型、首次下载 OCR / 语音包。

本地优先

全部内容存在本机 SQLite；模型 API Key 放在系统钥匙串；可随时导出、备份、恢复。

朗读与复习

系统语音或本地神经网络语音（Kokoro）；句级跟随、倍速、单句循环。

接其他 AI 工具

内置 MCP Server，Claude Code、Codex 等可读学习进度、帮你加生词（写操作需确认）。

开始用 Tibi

从 GitHub Releases 下载对应系统的安装包。尚未签名的版本：macOS 在 Finder 里右键 → 打开；Windows 遇到 SmartScreen 时选「更多信息 → 仍要运行」。
