# ferecord Logo：代码手记

## 需求与定位

用户明确 ferecord 的含义是「前端记录」，要求调研、设计 Logo 并替换首页左上角。品牌需要同时承接前端实践、随笔记录和个人作品，不能仅依赖本次首页的小宇宙题材。

原行星图标适合当前场景，但无法直接表达品牌名称。本次采用原创矢量图形「代码手记」：代码的左尖括号 + 三行记录 + 一颗暖金色记录点。保留小写 `ferecord` 字标，在下方补充「前端记录」。

## 调研与方向取舍

2026-11-17 查阅下列公开官方资料。参考的是图形与字标的组织、代码符号的语义和 SVG 的缩放能力，不复用其他品牌的图形。

| 资料 | 观察与本次启发 |
| --- | --- |
| [CodePen Brand Assets & Logos](https://blog.codepen.io/logos/) | 官方提供 Logo 的 SVG 文件与内联用法。采用可单独使用的图形与可读字标组合；不借用其立方体造型。 |
| [MDN：Basic HTML syntax](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax) | HTML 标签使用尖括号包裹。提取左尖括号作为「前端」线索，而不把完整代码片段塞进小图标。 |
| [MDN：SVG](https://developer.mozilla.org/en-US/docs/Glossary/SVG) | SVG 为矢量格式，适合不同尺寸展示。本次直接绘制路径，避免位图小尺寸模糊及引入图片生成依赖。 |

同时检索了 Notion 品牌规范，但该页面正文抓取失败，未作为细节依据。

| 方向 | 优点 | 本次取舍 |
| --- | --- | --- |
| FE 字母组合 | 与 front-end 缩写关联直接 | 需要额外解释 record；不采用 |
| 纸页、书签或笔 | 容易传达记录 | 前端辨识较弱；仅提取横向文字行的意象 |
| 代码左尖括号 + 三行手记 | 同时表达前端与记录，小尺寸仍清楚 | 采用；通过长短横线与暖金色句点形成固定构图 |

以上为本次设计判断，不代表对市场覆盖率或商标唯一性的结论。

## 图形与字标

- 图形画布：40×40。左尖括号的折点位于 `(4,20)`，右侧三行从 `x=22` 起笔，纵向分别为 `y=9/20/31`，长度为 `13/10/4`。三行逐渐缩短，末行以圆点收尾。
- 线宽：3；圆角端点和转角，兼顾代码的结构感与首页的温和气质。圆点半径 2.5，与短横线保留空隙。
- 主色：深青灰 `#34494e`；记录点：暖金 `#b5945e`。无需颜色也可辨认完整轮廓；暖金是强调，不作为必要信息。
- 字标：沿用本地系统无衬线、小写 `ferecord` 和暖金句点；桌面字号 24px，手机 23px。中文释义 9px，保持为辅助信息，不承担首页导航功能。
- 首页图形桌面 38px、手机 31px，整体首页链接最小高度 44px。图形无独立动画；蓝调模式图形随字标转为暖白，记录点保留暖金。
- 使用时保留至少约一条线宽的外部留白，不压扁、不旋转，不附加阴影或渐变。

## 实现与文件

- `sites/main/public/index.html`：首页 Logo 内联 SVG，使用 `currentColor` 跟随主题；链接无障碍名称为「ferecord 前端记录 · 首页」，装饰图形对读屏隐藏。
- `sites/main/public/styles.css`：双行字标、中文释义、记录点颜色与点击区域。
- `sites/main/public/assets/ferecord-mark.svg`：独立透明矢量标志，便于复用；固定为白昼标准配色。
- `sites/main/public/assets/favicon.svg`：同图形，加 48×48 奶油白圆角底；保留原文件路径。

本次仅替换主站品牌与标签页图标，不扩展到博客和产品站；不改变主站结构、域名或部署方式。无新增依赖、网络字体和运行脚本。
