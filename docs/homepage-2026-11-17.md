# ferecord 首页作品墙

本记录保留首页内容、角色选择与插画生成过程。后续 Three.js 动态环境、Blender 云团及相关交互以 [动态首页方案](homepage-3d-2026-11-17.md) 为准。

## 需求与设计

用户希望首页从简单的产品链接升级为作品墙，以悬浮卡片介绍持续更新的 Tibi 和画海，搭配有小王子式童话氛围的 3D 卡通绘图。

采用“好奇心的小小宇宙”作为整体意象：奶油白、雾蓝、蜂蜜金，带纸感的 3D 小星球。主插画由原创人物、读本、Tibi 藏狐、微型画框和蓝色花朵组成；文字与操作由 HTML 实现，不写进图片。主标题使用系统宋体，不依赖远程字体。

当前角色设定：人物穿浅底、蓝橙绿花纹的短袖花衬衣，搭配卷脚棕色长裤、厚袜和棕色系带靴，保留短前刺发型、阳光神态和肩臂少量自然训练线条。用户试看后否定短裤与凉拖方案，要求恢复此前 v2 穿搭。身旁的小狐狸改为 Tibi 藏狐，依照产品角色设定图保留宽方脸、奶油色脸颊、灰色脸缘、半垂眼和短胖身体；粉色格桑花发卡与最新应用图标一致。Tibi 卡片使用产品仓库当前的蓝紫渐变应用图标，不再使用旧 SVG Logo。

首页的职责是介绍两件作品并提供入口，不展开全部功能和下载流程。保留一个中央场景、两张完整作品卡、简短创作手记和页脚。桌面端自由构图，手机端回到线性阅读；没有轮播、拖拽或需要学习的操作。

## 产品依据

- Tibi：产品仓库 `README.md`（2026-11-17 查阅），重点为兴趣阅读、点词语境释义、AI 辅助、原句复习；当前可下载平台为 Apple 芯片 macOS。入口保持现有产品站。
- 画海：产品仓库 `README.md`、`docs/ios-app.md`（2026-11-17 查阅），重点为画海漫游、十八间时代展厅、细看及艺术家联系。App 发布记录当时为等待审核，首页仅提供已有 Web 入口，不宣称 App Store 可下载。
- 不使用旧“三万年长廊”品牌，不在首页展示会随网站与 App 版本变化的精确作品数量、付费额度或内购价格。
- 真实 ICP 备案号仍未提供，沿用 `noindex, nofollow` 和注释占位，不虚构号码。

## 交互与无障碍

- 作品卡整张为语义链接，标题作为链接名称；不在卡片中嵌套按钮。
- 默认有缓慢上下漂浮，卡片悬停或聚焦时回正。页脚按钮可以暂停、继续；不持久化用户选择。
- `prefers-reduced-motion: reduce` 时关闭动态和过渡，隐藏无意义的漂浮开关。手机端卡片不漂浮。
- 导航、作品链接与按钮可键盘访问，保留可见焦点和跳到作品入口。装饰图、星点、轨道不进入无障碍名称。
- 无 JavaScript 时作品内容与链接仍正常展示，仅隐藏漂浮开关。

## 本地验证与发布边界

主站继续通过 `python3 -m http.server 4173 --bind 127.0.0.1 --directory sites/main/public` 预览，Makers 仍直接发布 `sites/main/public/`。不改动画海同步目录，不改变域名、DNS 或部署配置。

本次为首页代码与素材的本地重构；Git 提交、推送和线上部署状态需单独记录，不能把本地预览视为已上线。

2026-11-17 验证结果：

- Chromium 在 320、390、768、1024、1440、1920px 六档宽度下没有横向溢出；两张卡片的边缘均在视口内，底部不覆盖创作手记。
- 首页全部图片解码成功；没有页面脚本错误或资源请求失败。
- 暂停与继续漂浮、按钮状态、系统减少动态效果、键盘跳转与焦点、禁用 JavaScript 后的内容与链接均通过。
- 通过受控导航响应验证 Tibi、画海与博客入口的点击目标；另行读取 Tibi 和博客线上入口、画海本地既有子路径，均返回 HTTP 200。
- 使用本机已有的 Playwright WebKit 可执行文件验证 390px 手机布局、图片解码与减少动态效果，通过。此为 WebKit 浏览器检查，不代替 iPhone 真机验收。
- `node --check sites/main/public/home.js` 与 `git diff --check` 通过。

预览截图：[桌面](assets/homepage-2026-11-17/desktop.png)、[手机](assets/homepage-2026-11-17/mobile.png)、[平板](assets/homepage-2026-11-17/tablet.png)、[手机 WebKit](assets/homepage-2026-11-17/mobile-webkit.png)。

前刺与藏狐修订后复核：新版图标与主插画全部解码成功，Chromium 的桌面、手机和平板布局检查通过，WebKit 手机图片与布局检查通过。Git 检查与脚本语法检查通过；仍为本地版本，未提交、推送或部署。

海岛穿搭修订后复核：主插画仍为 1200×800 透明 WebP，123,936 字节；Chromium 桌面、手机、平板和 WebKit 手机的图片解码及横向布局检查通过，四张预览截图已更新为短裤与凉拖版本。设计文档同步更新，`git diff --check` 与脚本语法检查通过。

最终取舍：用户否定短裤凉拖，要求恢复前一版。当前公开图片直接从保留的 v2 原图重新导出，恢复棕色长裤、厚袜和系带靴，文件回到 119,338 字节；前刺、花衬衣、阳光神态和 Tibi 藏狐保持 v2 形象。首页图片解码通过，预览截图同步恢复，设计文档以这一取舍为准。
